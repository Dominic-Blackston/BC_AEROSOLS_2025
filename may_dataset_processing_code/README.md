
MAIN FUNCTION: To get master_restricted.csv and master_comprehensive.csv
Code to run: combine_restricted_comprehensive.ipynb 
STEPS: 
1. Change ORGANIZATIONS to campaigns you want to combine. 
2. Change RESTRICTED_COMBINED_PATH and COMPREHENSIVE_COMBINED_PATH to directories where the restricted.csv and comprehensive.csv files are located. These paths are also where master_restricted.csv and master_comprehensive.csv end up.



SECONDARY FUNCTION: add_extra_cols_may_dataset.ipynb adds the SSA, AAE, and SAE columns to the original master_comprehensive and master_restricted datasets.
